# Finestra Viajes — propuesta de landing

Prototipo conceptual (Vite + React) para mostrar a Finestra Viajes cómo podría verse una landing moderna.

**No es el sitio oficial.**

## Stack

- Vite + React
- Tailwind CSS v4
- Framer Motion (con `prefers-reduced-motion`)

## Desarrollo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy

Subir a Vercel como proyecto estático (Vite). URL discreta, sin link desde el portfolio.

## Contenido

Copy y secciones locked en Notion (página Finestra). Destinos: RD, México, Brasil. Sin legajo ni WhatsApp en el mock.
